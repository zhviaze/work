# Life Card Wallet Demo

基于五段参考视频制作的静态 HTML 交互演示，供 Coshine 向 Life Card 说明业务体验。

## 运行与发布

无需安装依赖、构建或服务器后端。将整个目录放入 GitHub Pages 仓库即可：

- 入口：`/work/lifecard-demo/`
- 独立场景：`?scene=signup`、`?scene=ekyc`、`?scene=charge`、`?scene=cpm`、`?scene=mpm`
- 手机直接操作；电脑提供场景选择、步骤说明、下一步、自动演示和重置。
- 可以使用任意静态文件服务器本地预览，例如 `python3 -m http.server 8765 --directory lifecard-demo`。

## 后续修改颜色

所有颜色集中管理，组件样式不写业务配色：

1. **永久修改网站配色**：修改 `theme.js` 的 `DEFAULT_THEME`。`theme.css` 包含相同的首屏默认色和派生色；发布时同步其中的基础色，避免首次加载的色差。
2. **现场预览**：左侧展开「配色の調整」，修改主色、背景、卡片、文字、成功状态，或选择预设。手机在左上角菜单中打开。
3. **保存方案**：「設定を保存」导出 JSON，将其中的 `colors` 应用到 `DEFAULT_THEME` 即可发布为默认主题。导出本身不会修改服务器。
4. **恢复默认**：「初期配色に戻す」清除当前浏览器预览效果并恢复发布默认色。

色值含义：

| 字段 | 用途 |
| --- | --- |
| `primary` | 主色、App 顶栏、按钮、图标、重点文字 |
| `background` | App 页面背景 |
| `surface` | 卡片、输入区域基础背景 |
| `text` / `muted` | 正文 / 辅助文字 |
| `success` / `danger` | 完成成功 / 输入错误 |
| `capture` | 拍摄和扫描框 |
| `shell` / `shell-ink` / `shell-muted` | 外层演示工作台 |
| `code-ink` / `code-paper` | 演示码区域 |
| `unionpay-*` | 视频中保留的支付网络标识颜色 |

主色上的文字会自动选择深色或白色；浅色背景、边框、悬停和阴影通过 CSS 变量派生。favicon 同步主色。预览颜色仅保存到当前浏览器；当发布默认配色改变时，旧预览覆盖自动失效。

## 演示内容与数据

- 五个流程：注册、eKYC、银行充值、CPM、MPM。
- 金额、PIN、邮箱一致性、密码、验证码、确认勾选和额度有交互校验。
- 充值、付款、余额、记录和通知联动；同一次处理不会因返回重复记账。
- 自动演示填入虚构数据，走完所选流程后停止；可暂停和重新开始。
- 页面内数据只保存在内存中，刷新即恢复初始数据。只有主题配置保存在 localStorage。
- 注册密码和银行登录输入不会写入应用状态、localStorage、日志或网络请求。
- 默认 PIN：`1234`；邮件验证码：`123456`。可通过「デモ入力」填入。
- 所有姓名、邮箱、证件、银行、商户和交易均为虚构。未使用原视频中的证件、人物、账号或联系方式。
- 无真实支付、银行接入、开户、邮件发送、摄像头调用、生物识别或实名核验。eKYC 在本地模拟审批并更新演示额度。
- 页面中的额度、汇率换算与 PCI 等认证状态不构成真实产品声明。未将视频中的认证文字作为已验证的 Coshine 资质展示。
- QR 实际编码内容为 `DEMO ONLY - NO PAYMENT - Life Card presentation`，不包含付款链接；条码仅为示意图形。

## 文件

- `index.html`：工作台与手机外框
- `app.js`：页面、流程、校验、内存数据、自动演示
- `styles.css`：布局和组件，统一引用主题变量
- `theme.js` / `theme.css`：颜色配置、派生色、预览与导出
- `icons.js`：本地精选 Lucide 图标，无 CDN 依赖
- `assets/`：本地演示二维码、favicon、Lucide ISC 许可

`qa/` 为本地浏览器检查记录，不随网页发布。
